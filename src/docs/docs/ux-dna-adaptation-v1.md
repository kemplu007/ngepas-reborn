# UX DNA Adaptation for Ngepas v1

Dokumen ini menerjemahkan prinsip umum produk digital besar menjadi aturan Ngepas. Ini bukan peniruan visual atau branding perusahaan lain.

## Prinsip yang Diambil

Material Design 3 mendefinisikan layout sebagai susunan visual dan strategis elemen di layar untuk membangun hierarchy dan menarik perhatian ke aksi utama. Ia juga menyarankan layout beradaptasi berdasarkan breakpoint, bukan memperbesar layout mobile secara mentah.[1]

Material Design 3 menjelaskan bahwa spacing berfungsi untuk mengelompokkan konten, mengarahkan perhatian, dan membentuk personality produk. Proximity mengikat elemen yang memiliki konteks sama, sedangkan negative space memberi bentuk dan penekanan pada konten penting.[2]

Material Design 3 juga membedakan compact dan expanded layout. Pada compact, satu pane lebih sesuai untuk menjaga fokus; saat ruang bertambah, layout dapat mengungkapkan, mengubah ukuran, memosisikan ulang, atau menukar komponen jika fungsi dan ergonominya tetap setara.[3]

## Terjemahan ke Ngepas

| Prinsip | Aturan implementasi Ngepas |
|---|---|
| Scan cepat | Setiap viewport hanya memiliki satu fokus dominan: memahami, memulai, menjelajah, atau memutuskan. |
| Clarity | Satu headline utama, satu CTA utama, dan copy singkat. Metadata tidak boleh melawan hierarchy. |
| Whitespace | Jarak antar kelompok lebih besar daripada jarak antar elemen dalam kelompok. Section tidak dipadatkan demi menampilkan lebih banyak konten. |
| Rhythm | Heading, card, image, dan CTA memakai garis alignment serta ukuran berulang agar mata mudah memindai. |
| Progressive disclosure | Informasi detail baru muncul setelah user scroll atau masuk ke detail produk; Hero tidak memuat semua alasan sekaligus. |
| Mobile ergonomics | Mobile memakai satu kolom; search, menu, dan CTA tetap mudah dijangkau tanpa floating bar yang menutupi isi. |
| Adaptive layout | Desktop boleh menjadi dua kolom, tetapi bukan mobile yang dibesarkan. Komponen berubah posisi hanya jika fungsi tetap sama. |
| Decision support | Setiap product card menjawab: apa produknya, mengapa dipilih, kisaran harga, dan tindakan berikutnya. |
