# Prototype Header + Hero — Rejection Note v1

**Status:** Ditolak sebagai baseline visual.

**Branch terdampak:** `feat/prototype-header-hero-v1`

**Keputusan review:** Prototype dianggap terlalu kaku, terasa mlenuk, hierarchy belum mengena, dan spacing belum nyaman secara keseluruhan. Karena gap bersifat fondasional, patch kecil pada tombol, radius, atau motion tidak boleh dilakukan sebagai solusi utama.

## Hal yang Tidak Boleh Dibawa ke Baseline Baru

Prototype ini tidak boleh dijadikan sumber visual untuk Header + Hero berikutnya. Progressive search, perubahan wordmark ke favicon, Panduan Ngepas, dan eksperimen motion juga tetap berada di luar scope sampai wireframe mikro baru disetujui.

## Arah Iterasi Berikutnya

Iterasi berikutnya harus dimulai dari mockup resmi dan membedah empat hal secara terpisah: silhouette layout, hierarchy fokus mata, spacing rhythm, dan proporsi mobile. Setelah wireframe mikro disetujui user, implementasi dilakukan ulang dari baseline minimal tanpa membawa markup visual prototype ini secara otomatis.

`main` tidak disentuh dan branch produksi tidak diubah.
